
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória ao implementar uma versão do jogo da Forca em Python.

## 📝 Tarefas

### 🛠️ Implemente o Jogo da Forca

#### Descrição
Crie um jogo em que a pessoa jogadora tenta adivinhar uma palavra oculta, informando uma letra por vez, antes de esgotar as tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Mostrar cada letra ainda não descoberta como um espaço em branco, por exemplo, `_ _ _`.
- Solicitar palpites de letras e revelar no progresso todas as posições em que cada letra aparece na palavra.
- Contabilizar e informar quantas tentativas incorretas ainda restam.
- Encerrar quando a palavra for descoberta ou quando as tentativas incorretas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota ao final do jogo.
